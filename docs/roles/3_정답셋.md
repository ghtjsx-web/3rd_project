# 역할 브리핑: 팀원 3 (오분류 점검·수치 정답셋)

> AI에게: 이 사용자는 프로젝트에 처음 참여했고 코딩이 익숙하지 않으며, 주 3일 참여한다. 한 번에 한 단계씩, 무엇을 왜 하는지 먼저 설명한다. 이 역할은 코드보다 화면을 보고 확인·기록하는 일이 중심이다. 스크립트가 필요하면 AI가 만들고 사용자는 실행과 결과 확인만 한다. 루트 `AGENTS.md`와 `figindex/pipeline/AGENTS.md`를 따른다.

## 한 줄 요약
AI가 PDF에서 읽어 낸 **표 숫자와 분류가 정말 맞는지 사람 눈으로 확인**하고, 그 결과로 "정답지(정답셋)"를 만드는 일입니다.

## 전체에서 내 위치
`... → AI가 내용 읽기 → ★사람이 채점★`. 내가 만든 정답지로 팀 전체 성능 점수가 나옵니다.

## 왜 중요한가
이 서비스는 "여러 증권사 리포트의 같은 숫자를 나란히 비교"하는 게 핵심입니다. 숫자 하나가 틀리면 비교가 무의미해집니다. 정답셋이 있어야 "우리 시스템이 숫자를 95% 맞힌다"고 발표할 수 있습니다. 또 점검 기록은 팀장이 AI 프롬프트를 고칠 때 근거가 됩니다.

## 이 역할의 장점
- 하루 단위로 끊어서 해도 됩니다. 쉬는 날이 있어도 다른 사람 작업을 막지 않습니다.
- 이어서 할 때는 시트의 마지막 줄부터 계속하면 됩니다.

## 알아야 할 말
| 말 | 뜻 |
| --- | --- |
| 요소(element) | 표·차트·다이어그램 하나. 화면의 카드 하나 |
| TABLE / CHART / DIAGRAM | 표 / 차트(숫자를 그린 그래프) / 다이어그램(구조·흐름, 숫자 없음) |
| TableData | AI가 표를 읽어 만든 결과. `columns`(열 이름), `rows`(행들), `unit`(단위) |
| 정답셋 | 사람이 원문을 보고 직접 만든 "진짜 답" |
| cell_accuracy | 정답셋 숫자 칸 중 AI가 맞힌 비율. 목표 0.95 |
| table_valid_rate | 표 중 AI 결과가 형식 검사를 통과한 비율. 목표 0.90 |

## 관련 문서
- `docs/glossary.md` 2절: 표·차트·다이어그램 구분 기준과 애매한 경우
- `docs/glossary.md` 7절·9절: 표 숫자·단위 저장 규칙 (`1,234` → `1234`, `△1.2` → `-1.2`, 단위는 `unit`에)
- `figindex/data/analysis/targets.csv`: 종목별로 어느 증권사 리포트가 있는지

## 할 일
| 단계 | 할 일 | 확인 방법 |
| --- | --- | --- |
| 1 | glossary 2절 기준을 AI에게 예시로 설명받고, 화면에서 카드 10개로 연습 | 애매했던 카드 2~3개를 팀장과 확인 |
| 2 | 오분류 점검: 카드를 열어 [원문 보기]와 비교, 틀린 것을 공유 시트에 기록 (아래 양식). 목표 100건 | 시트 100줄 |
| 3 | 수치 정답셋용 표 30개 고르기: 같은 종목을 여러 증권사가 다룬 표 위주 (`targets.csv` 참고) | `element_id` 30개 목록을 팀장에게 공유 |
| 4 | 표마다 정답 JSON 만들기 (아래 방법) | `data/gt/table/`에 30개 파일 |
| 5 | AI에게 `cell_accuracy`, `table_valid_rate` 계산 스크립트를 만들게 하고 실행 | 두 숫자를 팀장에게 보고 |

### 2단계 오분류 기록 양식 (공유 시트)
`element_id` / 문서 이름 / 페이지 / 캡션 / 오류 종류 / 지금 값 / 맞는 값 / 메모

오류 종류는 다섯 가지 중 하나로 적습니다.
- **유형 오류**: TABLE·CHART·DIAGRAM 구분이 틀림
- **노이즈**: 로고·사진·표지 장식·머리말 같은 저장하면 안 되는 것
- **잘림**: 제목·단위·출처가 잘림
- **캡션 오류**: 제목이 원문과 다름
- **수치 오류**: 표 숫자나 단위가 원문과 다름

### 4단계 정답 JSON 만드는 방법
- 처음부터 쓰지 않습니다. AI에게 "이 `element_id`의 현재 `table_data`를 `data/gt/table/{element_id}.json`으로 복사해 줘"라고 시킵니다.
- 원문 PDF 페이지를 옆에 띄워 놓고 **틀린 칸만** 고칩니다. 규칙은 glossary 7절대로.

## 완료 기준
- 오분류 점검 100건 (11/20)
- 수치 정답셋 30개, `cell_accuracy`·`table_valid_rate` 측정 (11/27)

## 하면 안 되는 것
- 검수 탭에서 승인·반려 버튼 누르기 (실제 데이터가 바뀜. 기록은 시트에만)
- 정답 JSON을 AI 결과에 맞춰 고치기 (원문 기준으로만)
